# Local pose providers

`loadDetector('mediapipe' | 'movenet', base)` imports only the chosen SDK. `estimate(bitmap, timestamp)` takes monotonic seconds and returns original, unmirrored image pixels: top-left origin, x right, y down, and anatomical left/right. The caller owns and closes the bitmap; await each inference, discard results from old session epochs, and call `dispose()` on exit. Scores are not interchangeable probabilities across providers.

| Selection                          | Input and output                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MediaPipe Pose Landmarker **Full** | `@mediapipe/tasks-vision@0.10.32`, Google FP16 Full v1, CPU/WASM VIDEO mode, one pose. The SDK handles its own ROI/resize and returns 33 source-normalized landmarks. Multiply x by image width and y by image height. `z` is hip-relative depth in image-width pixels (not meters); `score` is visibility. An empty detection is `missing`. |
| MoveNet **SinglePose Thunder**     | `@tensorflow/tfjs@4.22.0`, Google TFJS graph v4. Full frame letterboxed with black padding to 256 x 256 RGB int32. Decode 17 normalized `(y,x,score)` triplets by removing the padding and dividing by scale. Fewer than four joints at score >= 0.30 is `missing`; tracker confidence gates still apply. No invented depth.                 |

## Preparing a static distribution

`npm ci` installs SDKs from the npm lock. `npm run assets` copies WASM glue and binaries from the pinned package, fetches the [versioned Full bundle](https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/1/pose_landmarker_full.task) and [versioned Thunder archive](https://api.kaggle.com/v1/models/google/movenet/tfJs/singlepose-thunder/4/download), and verifies SHA-256 before publishing them under `static/models`. See `scripts/assets.mjs` for all digests. Requires Node and `tar`; only initial preparation (or repair of a corrupted cache) requires model-host access. Preserve `static/models/{mediapipe,movenet}` as a build cache for offline builds. `npm run dev` and `npm run build` invoke preparation automatically. Deploy the complete static output, including model directories and notices. No model host, API key, cross-origin isolation headers or runtime download fallback is required in the browser.

The MediaPipe [Full model card](https://huggingface.co/litert-community/MediaPipe-PoseLandmarker-Full), [MoveNet Thunder listing](https://www.kaggle.com/models/google/movenet/tfJs/singlepose-thunder), and their SDKs specify Apache-2.0. Model bytes and runtime glue are unmodified. `static/models/LICENSE.txt` and `NOTICE.txt` travel with the deployed weights. These models are intended for on-device fitness use, not identification, surveillance or medical decisions.

## Real clip check (separate from BDD)

Run `npx playwright install chromium` once, then `npm run test:providers`. By default the host uses `ffmpeg` to extract `_knIf9vF4k4.mp4` at [101,104) seconds from the archive source listed in `_INPUT/training-data/sources-grid.csv`. To avoid that network fetch or avoid requiring ffmpeg, use `npm run test:providers -- /absolute/path/to/clip.webm push-up` with a local file. The harness compiles the actual providers and tracker, serves static files at `/allez.gamebus.eu/` without COOP/COEP, seeks identical decoded frames at 10 Hz (max 60 s) and uses a fresh browser context per provider. It rejects non-GET requests, off-subpath or off-origin requests, loading another model's assets, invalid landmark metadata and all-missing results. Quality metrics are reported, not assumed to pass. No webcam, frames, traces or third-party footage are shipped.

**Measured:** Playwright Chromium 159.0.8154.6 on macOS arm64 with software WebGL permitted. In the 30-frame push-up clip two cycles completed, with a third descent incomplete. Full: 0 missing, 0 tracker-lost, 0 reps (error -2), 25 ms median warm inference. Thunder: 0 missing, 4 tracker-lost, 0 reps (error -2), 228 ms median warm inference. First inference 158 ms / 8724 ms respectively, excluding model load. The foreshortened viewpoint did not satisfy the tracker. Desktop measurements are not phone performance estimates. Safari, physical iOS/Android phones and independent real sets for all eight exercises remain unverified.

## Optional models: evaluation, not deployment

**YOLO26n-pose:** `npm view @ultralytics/yolo@0.0.61 license` returns `AGPL-3.0`. The [Ultralytics policy](https://www.ultralytics.com/license) covers models as well as software, with AGPL or a separate enterprise license. Neither enterprise rights nor an AGPL distribution decision was supplied. No package, weights or runtime calls were included; no measured inference or accuracy claim. An approved license choice, fully local runtime/weight paths and the same clip and device checks are prerequisites.

**RTMO-s:** Evaluated [OpenMMLab's 2023-12-11 640x640 Body7 SDK export](https://download.openmmlab.com/mmpose/v1/projects/rtmo/onnx_sdk/rtmo-s_8xb32-600e_body7-640x640-dac2bf74_20231211.zip) locally. Archive SHA-256 `3da7ad88b209f9da8be87ba5c325610639af04de3b5c8a96649b98cd9e2848a2`; `end2end.onnx` SHA-256 `d0703d40d19f3921da51ae725402d5fdae4d2478c7442072d3101bd396f370d8`. Its `pipeline.json` and [rtmlib reference](https://github.com/Tau-J/rtmlib/blob/main/rtmlib/tools/pose_estimation/rtmo.py) specify aspect-preserving resize, top-left placement on fill 114, BGR NCHW float32, no channel normalization. Output `dets[0,N,5]` includes person scores; `keypoints[0,N,17,3]` contains pixel xy and confidence. Select the highest-scoring person over 0.7 (the top box survives NMS) and divide xy by the resize ratio. Do not apply heatmap decoding or centered-letterbox compensation.

To reproduce outside the distribution, extract the verified archive to an empty `$D`. In `$D` run `npm pack onnxruntime-web@1.22.0` then `tar -xzf onnxruntime-web-1.22.0.tgz`. In an isolated Python environment install `onnxruntime==1.19.2 opencv-python-headless==4.11.0.86`. From the project root:

```sh
python scripts/provider-check/rtmo-reference.py "$D" /path/to/push-up.webm
node scripts/provider-check/rtmo-check.mjs "$D"
```

With the first frame of the default excerpt resized to 960x540, Chromium WASM single-thread (no special headers) vs. native CPU ORT: max Euclidean error across 17 joints **1.743 original pixels**, max confidence difference **0.00027**, first inference **707 ms**. The check gates at 2 px / 0.02 score. This is one-frame parity, not exercise accuracy. The ONNX runtime is MIT; MMPose code is Apache-2.0. The archive includes configuration and weights but no explicit model redistribution license; framework terms do not by themselves clear the trained artifact and its training-data terms. Not bundled or selectable until rights and continuous tracking/device performance are validated.
